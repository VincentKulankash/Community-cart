# Community Cart

> A community marketplace where people buy, sell, and make private offers on second-hand items nearby.

---

## Where the code lives

**The complete, working implementation of this project is currently on the `feature/Vincent` branch — not on `main`.**

`main` only contains the initial scaffolding. All the working code (Flask backend, models, routes, tests, seed data, migrations) is on `feature/Vincent`. Follow the steps below to access and run it.
